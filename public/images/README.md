# Images

Place person and background photos here. The site automatically detects
whether a file exists and falls back to a styled placeholder when it
doesn't, so you can add these one at a time.

- `hero.jpg` — Hero section background (recommended: wide, dark-toned)
- `名称未設定のデザイン.png`, `cast/miyu.jpg` — Cast photos (recommended ratio 3:4 or 4:5)
- `staff/asatama.jpg`, `staff/isozaki.jpg` — Staff photos (recommended ratio 3:4 or 4:5)
